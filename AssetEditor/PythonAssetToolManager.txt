These generated files are ones you use to load the project and also at the end are generated by exporting them and later used for game I am making.


block_definitions.txt, item_definitions.txt both use JSON format.

generate item_texture_atlas.png and block_texture_atlas.png are atlases that have textures in a grid(item textures and block textures can have different sizes from eachother, typically i use 32x32 pixels for item textures and 16x16 pixels for block textures).

So in editor you should have option to make new project which creates a new directory with name you give it inside the projects directory in root folder of this editor.
Load option you should be able to select all this 6 files to load this things.
Save option generates new atlas pngs and new txt files and replaces old ones in currently loaded directory.

Above the place where you draw is option to put whatever ID you want but it automatically should first assign lowest available ID's.

Now for the item/block definitions which should have their own thing.
There you also should have on the left scrool wheel thing with all the entries. For items specifically when you create item, item_texture for it should be created and if you create item_texture, item should be created for it. Item ID is ID for an Item but item_texture ID is specifically tied to atlas but for items they always match and have same value. So stone_sword would have ID 34 for example and stone_sword would therofore be ID 32 in atlas.
You can convert ID to atlas positions by just doind for items for example in this case 34/32 = 1 meaning row 1 in atlas and then 34%32 = 2 meaning column 0.
then you get its located at (1,2) in grid which is (32, 64) pixel wise.
This is then used to make item_texure_definitions.txt in this format:
texture_size: 32 32
textures_per_row: 128
texture_rows: 128
1 stone_sword 0 0
2 iron_sword 16 0
3 diamond_sword 32 0
...
And here all entries for item entries are listed.
Same thing should be done for block textures.

Now biggest difference between items and blocks are that items cleanly map to their specific texture while blocks don't. For example you could have door but it uses 2 textures: door_upper and door_lower.
So for blocks you have same way to create them on left with that add entry or remove them but you dont create a block texture just because you made a block.
Also to mention when make a block you SHOULD make an item for it and item texture because every block is an item and every item has an item texture.
